# 解决合并冲突 — resolving-merge-conflicts

> **技能标识**: `resolving-merge-conflicts`
> **使用场景**: 当需要解决未完成的 merge/rebase 冲突时使用

## 它做什么？

帮助解决进行中的 git merge/rebase 冲突。通过分析冲突文件、追溯变更原因、理解原始意图，安全地解决每个冲突。

## 工作流程

### Step 1: 查看当前状态

检查 merge/rebase 状态、git 历史、冲突文件，了解整体情况。

### Step 2: 为每个冲突找一手来源

深入理解每个改动为什么发生、原始意图是什么：
- 读 commit message
- 查 PR 描述
- 查原始 issue/ticket

### Step 3: 逐冲突解决

对每个冲突文件：
1. 理解两侧改动的意图
2. 保留正确的一侧，或合并两者
3. 标记冲突为已解决

### Step 4: 验证

- 确保构建通过
- 确保测试通过
- 确保没有遗漏的冲突标记

## 约束

- ❌ 不盲目保留某一侧
- ❌ 不删除不确定的代码
- ✅ 每个冲突解决前理解两侧意图
- ✅ 解决后验证构建和测试通过
