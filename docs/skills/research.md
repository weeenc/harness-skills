# 外部事实查证 — research

> **技能标识**: `research`
> **使用场景**: 当用户要调研主题、收集文档或 API 事实、把阅读工作委派给后台 agent 时使用

## 它做什么？

启动一个**后台 agent** 做调研，主 agent 继续工作，不阻塞。针对问题调研，只查**一手来源**——官方文档、源码、规格、第一方 API——不是对它们的二手转述。每个断言都追回到拥有它的来源。

## 工作流程

### Step 1: 接收调研问题

用户提出一个需要外部事实查证的问题，例如：
- "调研 React 19 的 Server Components API"
- "查一下 Spring Boot 3.4 的虚拟线程支持"
- "找一下 Go 1.23 的 range-over-func 提案状态"

### Step 2: 启动后台 agent

启动后台 agent 执行调研，主 agent 继续对话。

### Step 3: 查证一手来源

- 只查官方文档、源码仓库、规格标准
- 不采信二手转述、博客、技术新闻
- 每个断言都附来源链接

### Step 4: 写入调研结果

将发现写进**单个 Markdown 文件**，引用每个断言的来源。保存到仓库里已有的此类笔记位置；若无则放在合理位置。

## 输出

调研结果写入 `.harness/wiki/research/` 下，按日期命名：`research/YYYY-MM-DD-<topic>.md`。

## 约束

- ❌ 不采信二手转述
- ❌ 不编造事实
- ✅ 每个断言附来源链接
- ✅ 找不到答案时如实说明，不猜测
